# ST → C Transpiler

Транспилятор: ST (Structured Text, IEC 61131-3) → C. Язык реализации: Go, стандартная библиотека.

## MVP-ограничения ST
- Только целочисленные переменные (`INT`)
- Конструкции: `IF / ELSE`, цикл `FOR`
- Простая арифметика над переменными
- Без вложенных конструкций

## Архитектура
Четыре последовательных этапа, каждый — отдельный Go-пакет:

| Этап | Пакет     | Статус         |
|------|-----------|----------------|
| 1    | `lexer`   | заглушка       |
| 2    | `parser`  | заглушка       |
| 3    | `ast`     | заглушка       |
| 4    | `codegen` | заглушка       |

## Текущее состояние (Этап 0 завершён)

### Созданные файлы
```
st2c/
├── go.mod                    # module st2c, go 1.22
├── examples/
│   └── example.st            # пример ST-программы для разработки
└── src/
    ├── main.go               # точка входа
    ├── lexer/lexer.go        # package lexer (заглушка)
    ├── parser/parser.go      # package parser (заглушка)
    ├── ast/ast.go            # package ast (заглушка)
    └── codegen/codegen.go    # package codegen (заглушка)
```

### Что реализовано
`src/main.go` — принимает путь к `.st`-файлу как `os.Args[1]`, читает его через `os.ReadFile`, выводит размер в байтах и содержимое. При ошибке — `log.Fatal`.

```
go run ./src examples/example.st
# ST source loaded: 214 bytes
# ----------------------------------------
# PROGRAM Example ...
```

### example.st — MVP-программа
Покрывает все целевые конструкции: объявление переменных (`VAR`), присваивание (`:=`), цикл `FOR ... TO ... DO`, условие `IF / ELSE`.

## Рабочий стиль
Этапы реализуются строго по одному. Переход к следующему — только после явного «переходим дальше» от пользователя.

## Следующий шаг — Этап 1: Lexer
Пакет `lexer` должен токенизировать ST-исходник. Ожидаемые типы токенов:
- Ключевые слова: `PROGRAM`, `END_PROGRAM`, `VAR`, `END_VAR`, `INT`, `IF`, `THEN`, `ELSE`, `END_IF`, `FOR`, `TO`, `DO`, `END_FOR`
- Идентификаторы, целочисленные литералы
- Операторы: `:=`, `+`, `-`, `*`, `/`, `>`, `<`, `=`
- Разделители: `:`, `;`
- `EOF`
